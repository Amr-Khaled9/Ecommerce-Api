# 🛒 E-Commerce API

##  Overview
A full-featured **E-Commerce REST API** built with Laravel.  
Supports product & category management, shopping cart, checkout, order lifecycle, and Stripe payment integration.  
Includes authentication with roles/permissions and caching for performance.  

##  Features
- **Products** → CRUD, search, filter by price, soft delete  
- **Categories** → CRUD + product–category pivot relation  
- **Cart** → add, update, clear items  
- **Checkout** → create orders & order items, order history & details  
- **Order Status** → enums + transition methods + admin controls  
- **Payments** → Stripe integration (PaymentIntent, webhooks)  
- **Auth** → multi-auth with Spatie Permission  
- **Performance** → caching for product–category data  
- **Testing Data** → factories & seeders  

## ⚙ Tech Stack
- **Backend**: PHP (Laravel)  
- **Database**: MySQL  
- **Payments**: Stripe  
- **API Testing**: Postman
